# 🎯 PersonaIQ — Where Customer Voices Become Campaign Intelligence  
*A Generative AI Project | IIM Ahmedabad (GAIM Course)*  

---

## 🧩 Overview  
**PersonaIQ** is a Generative AI–powered marketing insights application that transforms thousands of app reviews into **customer personas**, **sentiment reports**, and **LLM-generated ad copies**.  

Developed as part of the **Generative AI in Marketing (GAIM)** individual project at **IIM Ahmedabad**, the app helps marketers decode what customers *feel*, *need*, and *expect* — automatically.

---

## 🚀 Features  
✅ Upload or fetch Google Play Store reviews directly by App ID  
✅ Analyze customer **sentiment** using VADER (NLTK)  
✅ Perform **topic modeling** to identify recurring customer themes  
✅ Generate **AI-based personas** with name, tone, and motivation  
✅ Use local LLM (Ollama) or GPT API for rewriting **ad headlines, texts, and CTAs**  
✅ Export **review + sentiment CSVs** and detailed persona reports  

---

## ⚙️ Tech Stack  
| Layer | Tools / Libraries |
|-------|--------------------|
| Frontend | Streamlit |
| Data Handling | Pandas, NumPy |
| NLP | NLTK (VADER Sentiment Analyzer) |
| Topic Modeling | scikit-learn |
| App Reviews | google-play-scraper |
| LLM | Ollama (Phi-3) or OpenAI (optional) |
| Hosting | Render.com |
| Version Control | GitHub |
